MoxTags automatically detects Magic: The Gathering card names on any webpage and turns them into interactive elements with hoverable card image previews.

## Features

- **Automatic detection** — Recognizes card names in any text on any website
- **Hover previews** — See the full card image without leaving the page
- **Smart matching** — Handles card name variations and partial matches
- **Lightweight** — Minimal performance impact on page load

## Installation

MoxTags is available for Chrome and Firefox. Install it from your browser's extension store.
